## 1. Feature Overview

### Purpose

Manage the core legal entities of the system: consorcios (condominium legal
entities under CCC Art. 2044), their unidades funcionales with percentage
configurations, propietarios (owners/tenants) with tax IDs, and fiscal periods
with OPEN → CLOSED → ARCHIVED lifecycle.

### API Surface

10 endpoints (all ADMIN-only unless noted):

| Endpoint | Method | Purpose |
|---|---|---|
| `/consorcios` | POST | Create consorcio |
| `/consorcios/{id}` | GET | Get consorcio detail |
| `/consorcios/{id}` | PUT | Update consorcio |
| `/consorcios/{id}/ufs` | PUT | Configure unidades funcionales |
| `/consorcios/{id}/propietarios` | POST | Register propietario |
| `/consorcios/{id}/propietarios` | GET | List propietarios |
| `/consorcios/{id}/propietarios/{tax_id}` | GET | Find propietario by tax ID |
| `/consorcios/{id}/periodos` | POST | Open fiscal period |
| `/consorcios/{id}/periodos/{pid}/close` | PUT | Close period |
| `/consorcios/{id}/periodos/{pid}/archive` | PUT | Archive period |

### Missing Endpoint

`GET /consorcios` (list all) is not in the OpenAPI spec. The consorcio selector
in the layout uses a localStorage fallback. Documented in backend concerns §2.

### Domain Concepts

- **CUIT**: 11-digit Argentine tax identifier with checksum.
- **Matrícula CABA**: Buenos Aires city property registration number.
- **IVA Condition**: RI, EXENTO, MONOTRIBUTISTA, CF.
- **Percentage groups**: A, B, C — each group must sum to 100% across all UFs.
- **Period lifecycle**: OPEN (active, expenses can be added) → CLOSED (no new expenses, but payments allowed) → ARCHIVED (read-only, no mutations).
- **Propietario**: Owner or tenant linked to a UF. Has tax ID (CUIT/CUIL/DNI), IVA condition, contact info.

## 3. User Flows

### 3.1 Consorcio — Create

1. ADMIN navigates to `/consorcios/new`.
2. Form rendered: CUIT, razón social (required), nombre fantasía, matrícula CABA, domicilio, IVA condition (dropdown: RI/EXENTO/MONOTRIBUTISTA/CF).
3. ADMIN fills form and submits.
4. `POST /consorcios` with idempotency key.
5. On 201: redirected to `/consorcios/:id`.
6. On 409 (duplicate CUIT): inline error _"El CUIT ya está registrado."_
7. On 422 (validation): field-level errors.

### 3.2 Consorcio — View Detail

1. ADMIN navigates to `/consorcios/:id`.
2. `GET /consorcios/{id}` fetches data.
3. Tabs rendered: General (name, CUIT, matrícula, domicilio, IVA, status) | UFs | Propietarios | Períodos.
4. Edit button in General tab → `/consorcios/:id/edit`.
5. 404: _"Consorcio no encontrado."_ with back link.

### 3.3 Consorcio — Edit

1. ADMIN clicks Edit on consorcio detail.
2. Form pre-filled from `GET /consorcios/{id}`.
3. Fields: nombre fantasía, matrícula CABA, domicilio, IVA condition.
4. CUIT and razón social are read-only (immutable after creation).
5. `PUT /consorcios/{id}` on submit.
6. On 200: back to detail view with updated data.
7. On 422: field-level errors.

### 3.4 Unidades Funcionales — Configure

1. ADMIN navigates to `/consorcios/:id/ufs`.
2. Table displays current UFs: UF code, floor, unit, percentages A/B/C, exemptions.
3. ADMIN adds a UF: UF code (autogenerated or manual), percentages per group (A, B, C).
4. Inline validation: each group's percentages must sum to 100.00%.
5. ADMIN can edit existing UF percentages inline.
6. `PUT /consorcios/{id}/ufs` with all UFs.
7. On 200: success toast, UF table updates.
8. On 422: _"La suma de porcentajes del grupo A supera 100%."_ per group.

### 3.5 Propietarios — Register

1. ADMIN navigates to consorcio detail → Propietarios tab → "Registrar Propietario".
2. Form: tax ID type (CUIT/CUIL/DNI dropdown), tax ID, nombre completo, IVA condition, email, phone, UF selector, is owner checkbox.
3. CUIT field validates checksum format (11 digits).
4. `POST /consorcios/{id}/propietarios`.
5. On 201: redirected to propietario list tab.
6. On 409: _"Propietario con ese CUIT ya registrado."_

### 3.6 Propietarios — List

1. ADMIN views consorcio detail → Propietarios tab.
2. `GET /consorcios/{id}/propietarios` fetches list.
3. Table: nombre, tax ID, tipo, IVA condition, UF, email, is owner badge.
4. Search by tax ID input at top → calls `GET /consorcios/{id}/propietarios/{tax_id}` on submit.
5. Empty state: _"No hay propietarios registrados. Registre el primero."_

### 3.7 Fiscal Periods — Open

1. ADMIN views consorcio detail → Períodos tab.
2. Timeline/list of existing periods with status badges.
3. "Abrir Período" button → modal with period code (YYYYMM input), start date, end date.
4. `POST /consorcios/{id}/periodos`.
5. On 201: new period appears with OPEN badge.
6. On 409: _"El período ya existe."_

### 3.8 Fiscal Periods — Close

1. ADMIN clicks "Cerrar" on an OPEN period.
2. Confirmation dialog: _"¿Cerrar el período 202606? No se podrán agregar nuevos gastos."_
3. `PUT /consorcios/{id}/periodos/{pid}/close`.
4. On 200: status changes to CLOSED.
5. Close button hidden; Archive button appears.

### 3.9 Fiscal Periods — Archive

1. ADMIN clicks "Archivar" on a CLOSED period.
2. Confirmation dialog: _"¿Archivar el período 202605? Será de solo lectura."_
3. `PUT /consorcios/{id}/periodos/{pid}/archive`.
4. On 200: status changes to ARCHIVED.
5. Archive button hidden; period is read-only.

## 5. State Management

### TanStack Query Keys

| Query | Key | Endpoint |
|---|---|---|
| Consorcio detail | `["consorcio", consorcioId]` | `GET /consorcios/{id}` |
| Consorcio list | `["consorcios"]` | MSW/`GET /consorcios` (when available) |
| UF list | `["consorcios", consorcioId, "ufs"]` | Cached from consorcio detail or separate query |
| Propietario list | `["consorcios", consorcioId, "propietarios"]` | `GET /consorcios/{id}/propietarios` |
| Propietario by tax ID | `["consorcios", consorcioId, "propietarios", taxId]` | `GET /consorcios/{id}/propietarios/{tax_id}` |
| Period list | `["consorcios", consorcioId, "periodos"]` | Cached or from MSW fixtures |

### Mutations

| Mutation | Key | Endpoint | Invalidation |
|---|---|---|---|
| `useCreateConsorcio` | `consorcios.create` | `POST /consorcios` | `["consorcios"]` |
| `useUpdateConsorcio` | `consorcios.update` | `PUT /consorcios/{id}` | `["consorcio", id]` |
| `useConfigureUfs` | `consorcios.configureUfs` | `PUT /consorcios/{id}/ufs` | `["consorcios", id, "ufs"]` |
| `useRegisterPropietario` | `propietarios.register` | `POST /consorcios/{id}/propietarios` | `["consorcios", id, "propietarios"]` |
| `useOpenPeriod` | `periodos.open` | `POST /consorcios/{id}/periodos` | `["consorcios", id, "periodos"]` |
| `useClosePeriod` | `periodos.close` | `PUT /consorcios/{id}/periodos/{pid}/close` | `["consorcios", id, "periodos"]` |
| `useArchivePeriod` | `periodos.archive` | `PUT /consorcios/{id}/periodos/{pid}/archive` | `["consorcios", id, "periodos"]` |

### Consorcio Selector Integration

When a consorcio is created, the `ConsorcioSelector` in the layout must be
notified to refresh its list. This is done by invalidating the
`["consorcios"]` query key after `useCreateConsorcio` succeeds.

## 6. Error States

| Error | Trigger | UI Response | Component |
|---|---|---|---|
| Consorcio not found | 404 from `GET /consorcios/{id}` | Full page: _"Consorcio no encontrado."_ with link to `/consorcios` | ConsorcioDetail |
| Duplicate CUIT | 409 from `POST /consorcios` | Inline error on CUIT field: _"El CUIT ya está registrado."_ | ConsorcioForm |
| Invalid CUIT format | Client-side Zod validation | Inline error: _"CUIT inválido. Debe tener 11 dígitos."_ | ConsorcioForm |
| Percentage overflow | Client-side validation on UF config | Warning banner per group: _"Grupo A: 102.5%. La suma debe ser 100%."_ Submit disabled. | UfTable |
| Propietario not found | 404 from tax ID search | Inline message: _"No se encontró propietario con ese CUIT/CUIL/DNI."_ | PropietarioList |
| Period already exists | 409 from `POST /consorcios/{id}/periodos` | Inline error: _"El período ya existe."_ | PeriodTimeline |
| Cannot close/archive (wrong state) | 422 from period mutation | Toast: _"El período no está en el estado requerido para esta acción."_ | PeriodActions |
| Network error on mutation | Fetch failure | Toast with retry. Form remains filled. | All mutation components |
